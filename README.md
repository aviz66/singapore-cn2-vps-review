## 二、先把"CN2/9929/CMIN2"这几个词搞明白，不然评测都是玄学

很多人搜"新加坡 CN2 VPS"其实连 CN2 到底是什么都说不清。这里用大白话讲一遍，不然后面看评测数据只会越看越懵。

**CN2（AS4809）** 是中国电信专门建的一张高端骨干网，分 GT 和 GIA 两个等级。GT 是普通版，GIA 是 Global Internet Access 的缩写，属于优先级最高、丢包最低的那一档。通俗点说，CN2 GIA 就是电信给"重要客户"留的快车道，晚高峰别人堵在 163 干线上龟速，你能从这条专线一路畅通回国。

**AS9929（联通 9929）** 是中国联通的精品网，定位类似 CN2 GIA 之于电信。普通联通走的是 AS4837（10099）这条大路，9929 是给政企和 IDC 用的低延迟、低丢包版本。

**CMIN2** 是中国移动的精品回程，对应普通 CMI（AS58453）。移动家宽用户晚高峰经常掉速，原因就是回程挤在 CMI 上，切到 CMIN2 之后体验会明显改善。

所以当一家新加坡 VPS 商家说"三网精品回程"，意思是电信走 CN2、联通走 9929、移动走 CMIN2，三条线都给到顶配。这才是真正配得上"CN2 优化 VPS"标签的产品，而不是只在电信上去程挂个 CN2、回程又绕回 163 的伪精品。

记住这个判断标准：**看回程，不看去程**。去程很多商家都能伪装，回程才是真正决定你晚上 8 点看视频顺不顺、SSH 卡不卡的关键。
